# 高等数学（经济管理类）数字教材

主编：董高高、孙梅  
编者：姚洪兴、高安娜、韩敦、高翠侠、肖江、丁占文、许刚

本仓库提供 GitHub Pages 公开阅读入口。`index.html` 以内嵌方式打开已经发布的五章教材，保留原有排版、公式、动画、教师编辑、版本记录与学生反馈。教材正文和后台服务仍由现有教材站点提供，本仓库不是完整源码或数据库备份。请持续保留原站点。

支持章节深链接：`#chapter/c01` 至 `#chapter/c05`，以及 `#learn/c01s001` 等学习单元入口。页内翻页在教材内完成；浏览器外层地址不会随内嵌页面自动同步。

## 发布

GitHub Pages 使用 main 分支根目录。无需配置口令、令牌或数据库凭据。
